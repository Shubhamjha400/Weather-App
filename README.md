# Weather App using HTML, CSS, and JavaScript

This is a Weather App built using HTML, CSS, and JavaScript. The app allows users to check the weather forecast for any city, displaying information such as temperature, humidity, and weather conditions.

## Live Demo: https://weather-web-app5.netlify.app/

## Features
▫ Weather Information: Displays current weather details including temperature, humidity, weather description, and wind speed.

▫ Search Functionality: Users can search for weather data by city name.

▫ Responsive Design: The app is fully responsive, providing a smooth experience across mobile, tablet, and desktop devices.

▫ API Integration: Uses a third-party weather API (like OpenWeatherMap) to fetch real-time data.

▫ Dynamic UI: The user interface updates dynamically based on the weather data retrieved.

## Technologies Used
▫ HTML: Markup language for creating the structure of the web app.

▫ CSS: Styling language for making the app visually appealing and responsive.

▫ JavaScript: Used for handling user interactions and fetching data from the weather API.

▫ Weather API: API like OpenWeatherMap to get real-time weather data.
